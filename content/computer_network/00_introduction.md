# Computer Network

### Definition

- A Computer Network is a set of nodes connected by communication links

#### Nodes

- A node can be a computer, printer or any other device capable of sending/ receiving data generated by other nodes in the network.

#### Communication Links

- A communication link can be wired link or wireless link.

- Thar carries information only.

### Why Computer Network
1. Data Sharing 
2. Resource Sharing (printer scanner etc)
3. Efficient Communication (email, video conferencing, instant messaging etc.)
4. Cost Reduction


### Characteristics of CN

#### 1. Fault Tolerant
- Continue working despite failures
- Ensure no loss of service

#### 2.	Scalability
- Grow based on needs
- Have good [performance](../computer_network/network_performance.md) after growth

#### 3. Quality of Service

The ability to:

- Set Priorities
- Manage Data traffic to reduce loss, delay etc.

#### 4. Security

The ability to prevent:

- Unauthorized Access 
- Forgery
- Misuse 

The ability to provide:

- Confidentiality 
- Integrity 
- Availability
